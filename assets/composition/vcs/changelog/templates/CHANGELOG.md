# Changelog

All notable changes to this project are documented here.
Format: [Keep a Changelog](https://keepachangelog.com/en/1.1.0/);
versioning: [SemVer](https://semver.org/spec/v2.0.0.html).

This file deliberately deviates from Keep a Changelog 1.1.0 in one
way: released sections live one file per release under
[`docs/releases/`](docs/releases/) — the split Kubernetes and Node.js
use to keep a long-lived changelog scannable — and the root keeps
`[Unreleased]` plus the release index below. `scripts/cut-changelog.sh`
moves one into the other; nothing here is edited by hand at release
time.

Every user-visible change goes under `[Unreleased]`, in the same
commit as the change, under one of Keep a Changelog's six categories:
`Added`, `Changed`, `Deprecated`, `Removed`, `Fixed`, `Security`.
